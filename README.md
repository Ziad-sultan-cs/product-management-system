# Product Management System (CRUD App) 📦

A responsive dynamic web application for managing product inventories efficiently. Built using pure JavaScript (Vanilla JS), HTML5, and CSS3.

---

## 🚀 Features

- **Create:** Add new products with automatically calculated total price, taxes, ads, and discounts.
- **Bulk Creation:** Create multiple instances of a product at once using the `count` field.
- **Read:** Display all stored products in a structured, clean table layout.
- **Update:** Edit existing product details smoothly with auto-scrolling to the management form.
- **Delete & Delete All:** Remove individual items or clear the entire inventory with a single click.
- **Real-Time Search:** Instant search filter functionality by Product Title or Category.
- **Data Persistence:** Uses browser `localStorage` so data remains safe even after refreshing or closing the page.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Modern dark layout)
- **Logic:** Vanilla JavaScript (DOM Manipulation, LocalStorage API)

---

## 💻 How to Run

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Start managing your products!
